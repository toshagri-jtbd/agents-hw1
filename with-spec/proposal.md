# Мини-трекер учебных задач на неделю

## Цель

Вести список учебных задач на неделю и видеть, какая доля запланированных
часов уже выполнена.

## Границы

- Результат реализации — один автономный файл `tracker-v2.html` со встроенными
  CSS и JavaScript. CDN, внешние библиотеки и API-ключи не используются.
- Пользователь может добавлять и удалять задачи, менять статус выполнения
  и фильтровать видимый список.
- Сводка показывает общее количество часов, выполненные часы и процент
  выполнения по всему списку.
- Интерфейс читаем при ширине 390 px, поля и кнопки подписаны.
- Необязательное улучшение — сохранение задач в `localStorage` с продолжением
  работы в памяти и понятным сообщением при недоступном хранилище.

Эта поставка содержит только спецификацию. Реализация выполняется отдельным запросом.
