
##Запрос на спецификацию вместе с постановкой.

Сначала подготовь спецификацию мини-трекера в формате артефактов OpenSpec, код пока не пиши. Выдай четыре отдельных Markdown-блока: proposal.md (цель и границы), specs/tracker/spec.md (MUST и сценарии WHEN/THEN), design.md (данные и расчёты), tasks.md (чек-лист реализации и проверок). Используй все требования ниже, не расширяй задачу. Это работа в веб-чате: не утверждай, что запускал OpenSpec CLI или валидатор. После документов остановись.

Результат: автономный мини-трекер без CDN, внешних библиотек и API-ключей.  Один
tracker-v2.html с CSS и JavaScript внутри. 
Цель: мини-трекер учебных задач на неделю.
Данные задачи: id, title, hours, done. Стартовый пример: «Чтение» — 2 ч, done=true; «Практика» — 4 ч, done=false; «Повторение» — 2 ч, done=false.
Требования:
1. Добавление, удаление и переключение done реально меняют данные.
2. Название после trim непустое. Часы — число 0,5–24 с шагом 0,5. Пустое значение не равно нулю. Ошибка видна рядом с полем, данные формы сохраняются.
3. Прогресс = округление(100 × сумма часов done / сумма часов всех задач). Если задач нет — 0%, без NaN/Infinity.
4. Фильтр влияет только на видимый список. Итоговые часы и прогресс считаются по всем задачам.
5. При старте примера всего 8 ч, выполнено 2 ч, прогресс 25%. Если отметить «Практику» готовой — 6/8 и 75%.
6. Интерфейс читаем на ширине 390 px, без горизонтального скролла. Поля и кнопки подписаны.
Приёмка WHEN/THEN:
- WHEN включён фильтр «активные», THEN список меняется, прогресс остаётся 25%.
- WHEN введено пустое название или пустые/отрицательные часы, THEN задача не добавляется и видна ошибка.
- WHEN все задачи удалены, THEN итог 0 ч и прогресс 0%.
- WHEN «Практика» отмечена готовой, THEN прогресс 75%.
Необязательное улучшение: сохранять задачи в localStorage, а при недоступном хранилище
показывать понятное сообщение и продолжать работу в памяти.
Документы и реализация выполняются разными запросами. При подготовке спецификации код не писать. Фактически проведённые проверки перечислять отдельно от предложенных; запуск браузера не заявлять, если его не было.
