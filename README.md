# Домашнее задание 1

Вариант A — два способа разработки мини-трекера.

Модель: ChatGPT / GPT-6.2 Sol (средний режим)

## Запуск
Скачать нужный HTML-файл и открыть его в браузере (Chrome, Safari или другом).
— tracker-v1-5.html — версия без спецификации.
— tracker-v2-2.html — версия со спецификацией OpenSpec.
Приложения работают локально, без установки дополнительных библиотек.

## Отчет сравнения
Результаты тестирования обеих версий, обнаруженные ошибки, исправления и выводы находятся в файле report.md.

## Спецификация для tracker-v2-2.html 
подготовлена в формате OpenSpec без использования OpenSpec CLI.
— proposal.md — цель и границы проекта.
— specs/tracker/spec.md — требования и сценарии проверки.
— design.md — структура данных и логика расчётов.
— tasks.md — задачи по реализации и проверке.
